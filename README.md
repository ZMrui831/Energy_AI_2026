# 主动端数字孪生 + 被动端分位数 LSTM 的电力负荷预测系统

> **全国大学生 AI + 能源大赛参赛项目**
>
>  \| 上海交通大学联合赛事
> 从「人」的行为出发构建数字孪生基线，结合分位数 LSTM 概率预测，实现可解释、可干预的城市用电负荷预测。



***

## 项目定位

传统负荷预测从供电侧历史数据出发（黑盒、不可解释、极端天气外推差）。本项目提出**双端互补架构**：



| 维度   | 被动端（供电侧）        | 主动端（用户侧）          |
| ---- | --------------- | ----------------- |
| 视角   | 历史负荷 + 天气时序     | 人群行为 + 设备功率聚合     |
| 方法   | 分位数 LSTM + 保形校准 | 数字孪生行为状态机         |
| 输出   | 点预测 + 80% 置信区间  | 可解释基线 + 人群 / 设备分解 |
| 可解释性 | 低               | 高（可追溯到人群 × 设备）    |
| 干预模拟 | 不支持             | 支持（政策效果量化）        |

融合策略：**数字孪生基线作为物理先验特征输入 LSTM**（Physics-Informed Neural Network），并通过双数据集消融实验验证物理先验的真实作用边界。



***

## 核心创新点

### 1. 人群聚合数字孪生（主动端）

将城市人口分为 6 类典型群体，每群体有行为状态概率分布，通过设备功率聚合自底向上生成负荷基线：



* **人群分群**：上班族 31% / 学生 18% / 老年人 15% / 居家办公 8% / 商业服务 16% / 工业人口 12%（按城市产业结构校准）

* **行为状态机**：睡眠 / 外出工作 / 居家活动 / 烹饪 / 休闲娱乐 / 工业生产，6 种状态映射到 9 种设备开启概率

* **天气响应**：空调开启率的 Sigmoid 非线性调制（制冷阈值 26°C / 制热阈值 18°C）

* **学期感知**：学生群体在非学期时段自动切换为假期作息（利用 `school_period` 特征）

* **城市参数校准**：人口规模、人群比例、作息时段依据目标城市公开画像设定（人口普查、产业统计、作息文化），微观设备参数采用文献典型值并辅以敏感性分析

* **输出**：总负荷 + 人群 × 设备二维分解，支持精准需求响应

### 2. 分位数概率预测 + 保形校准（被动端）



* LSTM 同时输出 0.1 / 0.5 / 0.9 三个分位数，提供 80% 置信区间

* **Split Conformal Prediction**：用验证集（模型未见过的数据）残差计算区间半宽

* 校准后测试集覆盖率 **80.1%**，与理论值 80% 几乎一致

### 3. 物理引导混合模型 + 双数据集消融

数字孪生基线作为 LSTM 输入特征（物理先验）。通过**两种数据规模**的消融实验（同种子、同超参数、唯一差异为 dt\_baseline 特征）验证物理先验的作用边界：



| 数据规模     | Model A（无 DT）MAPE | Model B（含 DT）MAPE       | 结论              |
| -------- | ----------------- | ----------------------- | --------------- |
| 2 年（小样本） | 2.00%             | **1.88%**（RMSE ↓ 11.4%） | 物理先验有正则化增益      |
| 5 年（大样本） | **1.36%**         | 1.61%                   | 数据驱动已充分，先验增量被稀释 |

> **发现**
>
> ：物理先验在小样本场景下提供显著正则化收益（RMSE 降 11.4%），在数据充足场景下其核心价值转向
>
> **可解释性、概率校准与干预模拟**
>
> 。这一现象与物理引导神经网络领域的普遍经验一致。

### 4. 政策干预模拟（数字孪生独有能力）

可量化节能政策效果，例如「空调制冷阈值 +1°C」的夏季节能量（示例结果：约 16.7%），纯数据驱动模型无法实现。

## 实验结果（5.5 年全量数据，测试集 9585 小时）

### 主模型与基线对比



| 模型                | MAE (MW) | RMSE (MW) | MAPE (%) | R²         |
| ----------------- | -------- | --------- | -------- | ---------- |
| **LSTM（分位数，被动端）** | 17.93    | 24.65     | **1.53** | **0.9824** |
| GBDT 强基线（梯度提升树）   | 18.30    | 25.50     | 1.53     | 0.9812     |
| DT 纯数字孪生（主动端）     | 140.17   | 177.79    | 11.37    | 0.0859     |
| DT + 岭回归残差        | 125.18   | 155.59    | 10.39    | 0.2999     |

> 注：LSTM 与 GBDT 精度相当；本系统独有概率区间、可解释分解与干预模拟能力。GBDT 使用默认超参数作为公平基线。

### 消融实验（物理先验作用边界，同种子同超参）



| 数据规模   | Model A（无 DT）              | Model B（含 DT）                   | 结论                   |
| ------ | -------------------------- | ------------------------------- | -------------------- |
| 2 年小样本 | MAPE 2.00% / RMSE 31.15    | MAPE **1.88%** / RMSE **27.59** | RMSE ↓ 11.4%，先验有增益 ✅ |
| 5 年大样本 | MAPE **1.36%** / R² 0.9854 | MAPE 1.61% / R² 0.9822          | 先验增量被稀释，价值转向可解释性     |

## 数据说明



* **来源**：托库门市（Tucumán）电力负荷与气象公开数据集

* **时间范围**：2015-01-03 至 2020-06-27，小时级，共 48045 条（剔除负荷 < 300 MW 异常值后）

* **特征**：负荷 (nat\_demand)、温度 (T2M)、湿度 (QV2M)、风速 (W2M)、节假日、学期标记

* **预处理**：剔除负荷 < 300 MW 的异常值，派生周期编码特征（sin/cos），无缺失值

* **数字孪生参数来源**：人口（2010 普查 54.9 万）、产业结构（省统计局 PBG：服务业 66%/ 工业 23.8%）、作息（阿根廷文化作息，晚餐 21-23 时）、设备功率（家电标称值）
